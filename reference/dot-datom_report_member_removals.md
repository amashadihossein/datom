# Say What Was Dropped, and That Nothing Was Written

Say What Was Dropped, and That Nothing Was Written

## Usage

``` r
.datom_report_member_removals(dropped, left, n = 20L)
```

## Arguments

- dropped:

  The edit rows for the removed members.

- left:

  How many members remain.

- n:

  Maximum number of lines to print before truncating.

## Value

Invisibly `NULL`.
