# Refuse `sources =` (or Another Set-Path Argument) on an Ordinary Repo

Refuse `sources =` (or Another Set-Path Argument) on an Ordinary Repo

## Usage

``` r
.datom_refuse_sources_on_ordinary(arg)
```

## Arguments

- arg:

  The argument that was supplied.

## Value

Does not return; aborts with class `datom_sync_sources_on_ordinary`.
