# Build the Member a `new` Row Adds, From Its Source

Read through
[`datom_member()`](https://amashadihossein.github.io/datom/reference/datom_member.md),
which confirms the version exists and records the project the artifact's
own metadata declares. That project and the kind are then checked
against the row: the connection's label is what routed the read, and
nothing verifies a label.

## Usage

``` r
.datom_sync_new_member(row, conn, tags)
```

## Arguments

- row:

  One `new` row.

- conn:

  The connection for the row's project.

- tags:

  Labels for the new member.

## Value

A member record.
